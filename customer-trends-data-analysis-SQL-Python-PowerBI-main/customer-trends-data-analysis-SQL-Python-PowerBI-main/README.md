# 📊 Customer Shopping Behavior Analysis
### Data Analytics Project | SQL · Python · Power BI

An end-to-end customer behavior analytics project focused on understanding customer purchasing patterns, subscription behavior, category-wise sales and revenue distribution across different age groups.

The project uses SQL, Python and Power BI to explore customer shopping data and transform it into meaningful business insights through an interactive dashboard.

---

## 📌 Project Overview

Understanding customer behavior helps businesses make better decisions about product offerings, customer engagement, marketing strategies and revenue growth.

This project explores customer shopping behavior through data analysis and interactive visualizations.

The dashboard provides an overview of:

- Customer distribution and subscription status
- Average purchase amount and customer review ratings
- Revenue and sales across product categories
- Revenue contribution by age group
- Customer behavior across gender and subscription status
- Shipping preferences and purchasing patterns

## 🎯 Project Objectives

- Analyze customer purchasing behavior and shopping patterns.
- Understand subscription and non-subscription customer distribution.
- Compare revenue and sales across product categories.
- Examine purchasing trends across different age groups.
- Build an interactive dashboard for exploring customer data.
- Present business information through clear KPIs and visualizations.

## 📊 Power BI Dashboard

The Customer Behavior Dashboard provides an interactive view of important customer and purchasing metrics.

### Dashboard Preview

![Customer Behavior Dashboard](images/customer_behavior_dashboard.png)

### Key Performance Indicators

- **Number of Customers:** Displays the total customer count.
- **Average Purchase Amount:** Shows the average customer purchase value.
- **Average Review Rating:** Displays the average product review rating.

### Dashboard Visualizations

**1. Subscription Analysis**
- Percentage distribution of subscribed and non-subscribed customers.
- Interactive subscription status filtering.

**2. Revenue by Category**
- Compares revenue generated across product categories.

**3. Sales by Category**
- Visualizes category-wise sales performance.

**4. Revenue by Age Group**
- Compares revenue contribution across different customer age groups.

**5. Sales by Age Group**
- Analyzes sales distribution across age segments.

### Interactive Filters

The dashboard includes slicers for:
- Subscription Status
- Gender
- Product Category
- Shipping Type

These filters allow users to explore different customer segments and analyze changes in dashboard metrics.
